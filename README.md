# 麦门省钱大闯关

一款基于真实门店菜单信息的网页点餐闯关游戏。用户不再只是浏览菜单，而是在明确目标下完成选餐：控制预算、关注营养、尝试趣味搭配，或解决多人聚餐等真实场景问题。系统会实时反馈条件完成情况和预计星级，提交后给出统一规则下的正式结算。

> 本项目为非官方创新演示，不触发真实下单。商品、价格、优惠和营养信息以实际门店及官方渠道为准。

## 项目目标

- 把菜单比较转化为有目标、有反馈、可复玩的互动体验。
- 帮助用户理解套餐组成、预算取舍和营养指标。
- 通过场景化关卡降低多人点餐与组合选择的理解成本。
- 展示 MCP 工具在真实数据获取、规则计算和交互产品中的集成方式。

## 主要功能

- **四个赛道、二十个关卡**
  - 省钱大师：预算和优惠组合挑战。
  - 营养控卡：热量、蛋白质、脂肪和碳水挑战。
  - 奇葩整活：辣味、甜咸反差和趣味组合挑战。
  - 场景模拟：加班、同事午餐、亲子和多人聚会等情境。
- **门店菜单与套餐组成**：展示商品、价格和套餐默认组成。
- **实时预演与正式结算**：选餐时查看预计结果，提交后使用同一判题引擎结算。
- **账号与进度**：注册、登录、关卡星级、历史成绩、门店偏好和成就。
- **数据降级**：未配置 MCP 或实时接口暂不可用时，可使用项目内菜单快照完成基础演示。

## 技术结构

```text
MDL-game/
├─ client/                  React + Vite 前端
├─ server/                  Express + Node.js 后端
│  └─ src/
│     ├─ engine/            求解、计价和判题
│     ├─ mcp/               MCP 数据接入
│     └─ data/              菜单快照与基础数据
├─ shared/                  前后端共用挑战规则
└─ package.json             项目统一脚本
```

运行环境建议使用支持 `node:sqlite` 的较新 Node.js 版本（建议 Node.js 22 或更高版本）。

## 安装

在项目根目录执行：

```powershell
npm run setup
```

该命令会安装根目录、服务端和客户端依赖。

也可以分别安装：

```powershell
npm install
npm --prefix server install
npm --prefix client install
```

## 环境变量

在 `server` 目录新建 `.env`。不要将真实密钥提交到代码仓库。

```dotenv
MCD_MCP_URL=你的麦当劳MCP服务地址
MCD_MCP_TOKEN=你的访问令牌
AMAP_MAPS_API_KEY=可选的高德Web服务Key
PORT=3001
```

说明：

- `MCD_MCP_URL`：配置后启用实时 MCP 数据；不配置时使用项目内菜单快照。
- `MCD_MCP_TOKEN`：MCP 服务需要鉴权时填写。
- `AMAP_MAPS_API_KEY`：可选，用于 IP 定位、逆地理编码和门店距离补充。
- `PORT`：服务端端口，默认 `3001`。

前端默认通过同源 `/api` 访问后端。若前后端分开部署，可在前端构建环境中配置：

```dotenv
VITE_API_BASE=https://你的后端地址
```

## 本地运行

### 同时启动前后端

```powershell
npm run dev
```

默认访问：

- 前端：`http://localhost:5173`
- 后端：`http://localhost:3001`

### 分别启动

```powershell
npm run dev:server
npm run dev:client
```

### 生产构建

```powershell
npm run build
```

构建结果位于 `client/dist`。

## 使用示例

1. 打开前端页面，注册并登录。
2. 在首页确认或切换门店。
3. 选择一个赛道和已解锁关卡。
4. 阅读关卡要求，例如主食、小食和饮品份数，以及预算或营养限制。
5. 将商品或套餐加入餐盘，查看套餐具体组成和实时条件反馈。
6. 根据预计星级调整组合。
7. 提交方案，查看正式星级、实付金额和判定详情。
8. 返回关卡列表继续挑战；系统会记录进度和最近赛道。

## 数据与隐私

- 用户账号、进度和会话默认保存在服务端本地 SQLite 数据库中。
- 提交源码时不要包含 `server/data/game.db`、`game.db-wal`、`game.db-shm`。
- 不要提交 `.env`、访问令牌、API Key、`node_modules` 或本地构建缓存。
- 公开部署时应为数据库配置持久化存储，并根据访问规模增加限流和安全配置。

## 目标用户与使用场景

- 想快速比较点餐组合的普通用户。
- 关注预算、营养指标或多人搭配的用户。
- 需要演示 MCP 工具与真实业务数据结合方式的开发者、学生和创新项目团队。

## 项目边界

本项目用于互动体验和技术演示，不代表品牌官方渠道，不保证全局最低价，不提供医疗或个性化饮食建议，也不替代实际门店菜单和官方营养说明。
